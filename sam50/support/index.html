고객지원

momongs Inc.의 모바일 게임 삼국 · 장성의 길에 관한 문의는 help@momongs.com으로 보내주세요.

오류 문의에는 기기 모델, OS와 게임 버전, 문제가 발생한 화면과 재현 방법을 적어주세요. 비밀번호, 확인 코드, 결제 카드 번호는 보내지 마세요.

구매 복원

구매에 사용했던 스토어 계정과 게임 계정으로 로그인한 뒤, 게임의 계정 관리에서 구매 복원을 선택하세요.

계정 및 데이터 삭제 요청

게임에서 계정 관리 → 보안 · 계정 삭제 → 계정 삭제를 선택하세요. 게임을 이용할 수 없다면 계정 삭제 요청 이메일로 연락해 주세요. 계정 소유 확인에 필요한 정보는 회신으로 안내합니다.

Three Kingdoms: General's Path Support

For help with the mobile game from momongs Inc., contact help@momongs.com.

For a bug report, include your device model, OS and game version, the affected screen, and steps to reproduce it. Keep passwords, verification codes, and payment card numbers private.

Restore purchases

Sign in with the same store and game accounts used for the purchase, then select Restore Purchases in Account Management.

Request account and data deletion

In the game, open Account Management → Security · Account Deletion → Delete Account. If you cannot use the game, email a deletion request and support will explain how to confirm that you own the account.
